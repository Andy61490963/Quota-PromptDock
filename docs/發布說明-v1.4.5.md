# Quota PromptDock v1.4.5

發布日期：2026-09-29。適用 Windows x64，不需安裝 Python。

## 新增操作體驗

- **首次使用與連線引導**：選擇追蹤 Codex、Claude Code 或兩者，查看安裝、登入與連線狀態；既有使用者可從設定或系統匣開啟。
- **懸浮額度摘要**：滑鼠停留或鍵盤聚焦時，查看最多四個額度週期、重置倒數、資料時間與同步失敗提示；支援小螢幕捲動。
- **指令搜尋與預覽**：「更多指令」可搜尋名稱與內文，查看全文後確認貼上；原有前八個快捷按鈕保留。

## 修正與效能

- 補入 GPT-6 Sol／Luna 的 Standard API 等值估算與長上下文費率。
- 未變動的 Token 紀錄略過開檔，統計不變時略過表格重建；每小時及手動更新仍進行完整巡檢。
- 修正多則額度通知、指定來源沒有資料、來源切換後的待查詢要求及登入狀態競態。
- 更新下載核對附件大小與 SHA-256，完成暫存後才交接舊程式；等待新版啟動確認，失敗時嘗試回復程式、捷徑及開機設定。
- 發行流程固定依賴、核對標籤版本，執行測試與打包啟動檢查，並提供校驗清單。

## 安裝與更新

下載 [QuotaDock-Windows-x64.exe](https://github.com/Andy61490963/Quota-PromptDock/releases/download/v1.4.5/QuotaDock-Windows-x64.exe)。既有版本也可透過「有新版」按鈕更新；「立即更新」用來重新整理用量。

一般雙擊為免安裝執行。手動升級時，先從系統匣結束舊版，再於下載資料夾執行：

```powershell
.\QuotaDock-Windows-x64.exe --install
```

安裝位置為 `%LOCALAPPDATA%\Programs\QuotaDock\QuotaDock.exe`，並建立桌面捷徑。既有設定、常用指令與 Token 資料庫沿用。手動執行免安裝版前也應先結束舊版，避免只喚醒原有視窗。
