# v1.4.8：修正重複更新提示、加速統計、補入 GPT-6.1 Sol 估價

發布日期：2026-10-21。

## 更新流程

更新下載完成但舊執行檔持續被 Windows 拒絕替換時，先前版本會保留並重開舊版，因此再次提示相同更新。v1.4.8 每次安裝到新的版本目錄，不覆寫原 EXE；等新版主視窗進入事件迴圈後，才更新桌面捷徑、開機偏好及目前版本指標。

- 安裝／啟動／設定失敗時，回復舊指標與捷徑／開機設定，重新開啟原版。
- 舊版與失敗後未啟用的新版檔案可保留，回復不依賴刪除遭占用的 EXE。
- 安裝鎖阻止多份安裝器同時更改設定；指標路徑須位於安裝版本目錄。
- 設定中顯示目前版本，滑鼠提示顯示實際執行位置。
- 不更改防毒、唯讀屬性或檔案 ACL；保留既有指令、設定及 Token 資料位置。

## 統計效能

新增 `responses(turn_id)` 索引，加速舊紀錄涵蓋率的相關子查詢。既有資料庫在啟動時自動補建，不改變統計結果。

本機資料庫副本約 2,716 筆回應、1,985 筆舊回合，各跑五次取中位數：今日報表約 221 → 3.7 ms，全部報表約 231 → 12.2 ms。這是報表查詢的改善，並非整個 App 的速度倍率。

## GPT-6.1 Sol

依 [OpenAI 官方 API 價格](https://developers.openai.com/api/docs/pricing)與[模型說明](https://developers.openai.com/api/docs/models/gpt-6.1-sol)補入每百萬 Token 的 Standard 單價：

| 類型 | 美元 |
|---|---:|
| 輸入 | 2.00 |
| 快取讀取 | 0.10 |
| 30 分鐘快取寫入 | 2.50 |
| 輸出 | 10.00 |

單次輸入超過 272,000 Token 時，整次輸入與快取費率乘 2、輸出乘 1.5。這是 API 對照估算，不代表訂閱帳單；未包含 Fast／Ultrafast、12 小時快取、地區、工具及稅費。新模型 Token 仍由紀錄自動收錄，價格表尚不會自動同步。

## 驗證

完整 Windows 測試、打包展示啟動，以及前一正式版至本版的真實 EXE 升級與失敗回復。新增的版本目錄驗證在舊 EXE 持續被原生 Windows 不允許刪除分享的句柄鎖定時進行；設定故障時須回復舊版。隔離驗證不操作真實使用者捷徑或 HKCU，實機安裝另行核對。

詳細結果見[驗證紀錄](../驗證紀錄.md)。
