# Quota PromptDock v1.4.6

發布日期：2026-09-30。此版本修正 App 內更新安裝失敗的兩種可重現情境。

## 修正內容

- **舊程式自然退出時不再誤判失敗**：Windows 正在停止舊版的期間，程序可能自行結束。現在只在確認該程序已不存在時略過對應錯誤；仍在執行或權限遭拒時仍會中止並回復。
- **等待舊免安裝版交接完成**：從 v1.4.4 更新時，舊視窗服務可能還沒釋放，導致新版喚醒舊版後以結束碼 0 離開。安裝器現在會在共用的 30 秒期限內逐步延長重試間隔，直到收到新版就緒訊號。
- **保留真正啟動失敗的回復機制**：非零結束碼、已就緒後退出，以及逾時仍未完成啟動，均不當成更新成功。
- **安裝錯誤可追查**：顯示失敗步驟與可讀原因，並將例外鏈及 Windows 輔助程序錯誤寫入本機 `install.log`。紀錄包含安裝錯誤與本機路徑，不包含登入憑證、環境變數、常用指令或 Token 用量。

## 更新方式

1. 若 App 還顯示 v1.4.5 的更新按鈕，請從系統匣結束程式，再重新開啟以取得最新版本。
2. 點選 **v1.4.6** 更新按鈕。更新會保留既有設定、常用指令及 Token 資料庫。
3. 也可[下載 Windows x64 執行檔](https://github.com/Andy61490963/Quota-PromptDock/releases/download/v1.4.6/QuotaDock-Windows-x64.exe)，先結束舊版，再執行：

```powershell
.\QuotaDock-Windows-x64.exe --install
```

如仍失敗，請提供視窗顯示的失敗步驟與 `%LOCALAPPDATA%\CodexUsageWidget\install.log`，以便判斷程序、權限、備份或啟動階段的實際原因。

## 驗證範圍

完整 **253 項自動化測試通過**。新增 Windows 原生 PowerShell 程序退出競態測試，以及安裝啟動重試、失敗回復、診斷與唯讀備份的回歸測試。另以隔離子程序重現 v1.4.4 單例服務尚未釋放時，新版退出 0 且沒有就緒訊號的情境，並驗證修補後可成功完成交接。

原本的 v1.4.5 錯誤視窗沒有底層原因，無法僅憑截圖確定每次失敗的原因；本次修正已重現的問題並補齊後續診斷。完整結果見[驗證紀錄](../驗證紀錄.md)。
