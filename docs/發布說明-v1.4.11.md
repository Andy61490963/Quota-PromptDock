# v1.4.11：修正工作列釘選重開舊版

發布日期：2026-10-21。

舊安裝器只更新指定名稱的桌面捷徑。工作列釘選是獨立的捷徑，因此即使新版已成功啟動，關閉後點原本的工作列圖示，仍可能開啟先前的 EXE。

- 新增固定的 `QuotaDockLauncher.exe`。它每次啟動都讀取 `current.json`，開啟目前已啟用的版本，不把版本號寫死在捷徑裡。
- 桌面捷徑、開機啟動，以及能確認屬於本工具的既有工作列釘選，都改用固定入口。保留原釘選名稱與啟動參數，不新增釘選，也不修改其他軟體的捷徑。
- 固定啟動程式有效時，後續升級不覆寫它；既有版本的主 EXE 繼續保留，避開檔案被占用導致更新失敗的問題。
- 捷徑及啟動程式納入安裝回復；捷徑或開機設定失敗時，還原原本捷徑並重新開啟上一版。
- 捷徑讀寫改用原生 Unicode `IShellLinkW`，支援英文 Windows 上的中文路徑與釘選名稱。
- 固定入口檢查啟用目標必須位於安裝版本目錄，拒絕遺失、越界或透過 junction／symlink 跳出目錄的目標。

可透過程式內更新或下載此版安裝。若 Windows 仍快取非常舊的釘選，或舊捷徑指向無法確認的免安裝檔，需解除舊釘選，再把新版桌面捷徑釘選一次。之後固定入口會跟隨更新，不需每版重釘。

沿用 v1.4.10 Token 小卡 UI、官方價格自動同步及既有用量資料。驗證包括原生 Windows 捷徑的更新後重開、再次切換版本而不更換捷徑、啟動程式被鎖定時繼續更新、失敗回復，以及打包 EXE 實際程序與 READY 檢查。
