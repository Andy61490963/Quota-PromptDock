# v1.4.9：自動同步官方模型價格、主畫面版本號

發布日期：2026-10-21。

## 自動同步 OpenAI 官方價格

- 讀取 [官方價格頁的 Markdown 表格](https://developers.openai.com/api/docs/pricing.md)，只採 Standard 文字 Token 單價；不需 API Key，也不傳送本機用量、指令或帳號資料。
- 沒有快取或資料超過 24 小時時，在獨立背景執行緒同步。之後每 24 小時檢查，按「立即更新」也能重查（最多每分鐘一次）；未知模型可提前檢查（最多每小時一次）。
- 新模型出現在可辨識的官方 Standard 表格後，會自動納入；既有 Token 紀錄及明細立即重新估價，不必重匯、重開或逐次發布 App。
- 來源或格式無法確認、價格衝突、網路或寫入失敗時，保留最後成功快取並顯示狀態，1 小時後重試。沒有快取時沿用內建價格，不將未知價格當成零。
- 同步資料先驗證、再原子寫入；每次資料庫查詢固定使用同一份價格快照。有短／長上下文表時依明示門檻與各欄單價計算，不推測新模型倍率；單一費率表不自行加價。
- Token 卡片顯示價格來源及同步時間，金額提示包含規則；小視窗保留提示內容。快取位於 `%LOCALAPPDATA%\CodexUsageWidget\model_prices.json`。

此功能追蹤官方可辨識的表格資料；若官方更改文件結構，會保留快取並標示同步失敗，可能需要更新解析器。估價仍以 Standard 及 30 分鐘快取寫入為基準，不代表實際訂閱／API 帳單，不含 Fast／Ultrafast、12 小時快取、地區、工具及稅費。未列出的既有模型沿用內建價格。
