# v1.4.10：更清楚的 Token 用量小卡

發布日期：2026-10-21。

- 累計 Token 與 API 等值費用改為左右雙欄，用量與費用分別使用清楚的標題與數值。
- 用量下方增加回應次數；價格同步時間移至費用下方，完整日期、來源與計算規則保留在滑鼠提示中。
- 單一模型省略重複的滿格占比長條及「1 個組合」；多個模型繼續顯示占比與未展開組數。
- 「統計不完整」、讀取異常與價格同步失敗使用琥珀色提示；Token 更新失敗使用紅色提示，仍保留先前數值。
- 部分回應可估算時，費用標題清楚標示「部分估算」；未知價格繼續顯示「無法估算」，不當成零。
- 「查看全部」改名為「查看明細」，原本的模型、推理強度及回合明細功能保留。

此版調整資訊呈現，不改變 Token 收錄、官方價格同步與費用計算規則。沿用版本目錄安裝及失敗回復，指令、設定與既有 Token 紀錄持續保留。

驗證涵蓋完整測試、320／344／360 像素寬小卡與 430／530／740／940 像素高主視窗、無資料／部分估價／同步失敗／大金額呈現，以及打包 EXE 啟動、前一正式版升級與失敗回復。
