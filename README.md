# Quota PromptDock

沿用 [Andy61490963/Quota-PromptDock](https://github.com/Andy61490963/Quota-PromptDock) 的 Windows 額度小工具，新增常用指令與一鍵貼上。保留深色面板、綠色圓環、Claude Code、系統匣、通知和側邊收合。

1.4.2 保留原本額度版面，依可用高度調整常用指令的可見範圍，讓 Codex 額度卡片與重置時間完整顯示；統一 Token 日期選單和「查看全部」的尺寸與樣式。延續 1.4.1 的強度標籤、比例條、明細卡片及模型切換修正。

![主畫面（示範資料）](token-preview.png)

## 開始使用

1. 到 [最新正式版本](https://github.com/Andy61490963/Quota-PromptDock/releases/latest) 下載 `QuotaDock-Windows-x64.exe` 並執行，不需要另外安裝 Python。若舊版正在執行，先從系統匣結束，或使用 App 提示的更新按鈕。
2. 先點一下 Codex、記事本或瀏覽器的輸入框，再點小工具的指令按鈕。
3. 小工具會複製完整文字、切回前一個視窗，執行 Ctrl＋V；不會按 Enter 或自動送出。
4. 若視窗切換或貼上受 Windows 限制，回到輸入框按 Ctrl＋V。
5. 「更多指令」顯示全部；「編輯指令」可新增、修改、刪除與上下移動，最後按「儲存變更」。儲存失敗時視窗與編輯內容會保留，排除檔案權限問題後可直接重試。其他操作結果以短暫提示顯示。

小螢幕會縮小額度摘要及 Token 摘要列數，「立即更新／設定」保持可見。滑鼠移至上方額度區可捲動查看 Claude 完整內容；指令區空間不足時可捲動，所有指令仍可操作。

視窗高度會隨內容自動收緊。Claude 未安裝或卡片內容較少時，常用指令緊接在下方，不保留大片空白；視窗底部位置維持不變。

要讓文字、按鈕與整個介面一起放大或縮小，開啟「設定 → 介面縮放」，選擇 75%、90%、100%、110%、125% 或 150%，再按「儲存並套用」。變更比例後會重新開啟小工具並記住選擇；100% 為預設。此比例會疊加 Windows 本身的縮放，大比例下空間不足時可捲動額度、指令及設定內容，底部儲存按鈕保持可見。

首次開啟預設在右下角。可拖曳頂部調整位置，按右上角收合成圓形圖示。系統匣選單可顯示或結束程式；重複啟動會叫出既有視窗。首次使用預設手動啟動，設定內可開啟登入 Windows 時自動啟動。

| 按鈕 | 用途 |

| Commit＋推送 | 說明為什麼修改、改動內容、影響與測試，再推送遠端 |
| 同步遠端 | 確認分支、保留本機修改並同步 |
| 查流程 | 找入口、呼叫順序與相關檔案 |
| 查錯誤 | 找根因並提出最小修正 |
| 修改＋測試 | 完成修改與必要驗證 |
| 前端文件 | 整理欄位、API 與前端串接流程 |
| 查表／SQL | 釐清資料表關聯與查詢 |
| 白話說明 | 使用繁體中文與簡單例子解釋 |

這些按鈕只是貼上文字。涉及 Commit、推送等動作，仍需你在目標 AI 工具確認並送出指令。

## 額度

顯示帳號已用／剩餘百分比，**不是累計 Token 數量**。上方圓環保留原有最低剩餘額度邏輯，可在設定調整。重置時間固定使用台灣時間。

啟動、展開及「立即更新」都會查詢。全新設定預設每 60 秒更新，既有更新頻率仍保留。失敗會保留本次執行中最後成功的資料並標示；沒有資料則顯示「尚無資料」。Codex 未安裝或未登入不影響常用指令。

Codex 使用官方本機 App Server 的 `account/rateLimits/read`，沿用目前登入環境，不需要填寫 API Key。Claude Code 沿用原專案的卡片，直接顯示在 Codex 額度下方；常用指令接在後面。

## Codex Token 用量

![Token 用量示範畫面，數字為示範資料](token-preview.png)

- **位置與開關**：區塊位於「常用指令」上方。到「設定 → 顯示 Token 用量」勾選或取消，再按「儲存並套用」，立即生效；隱藏不停止背景記錄。
- **日期**：今日、近 7 天、本月、全部，預設今日，會記住選擇。日期使用台灣時間，近 7 天包含今天和前 6 個日曆日。
- **摘要**：總數涵蓋所有組合；下方最多顯示前三個模型／強度，剩餘組合顯示「另有 N 組」。小螢幕可能只顯示總數，仍可按「查看全部」。
- **明細**：「查看全部」顯示每個組合的輸入、輸出、總 Token；按「快取與推理明細」展開附屬欄位。選取一列查看各回合用量，每頁 100 回合。「統計範圍與說明」可查看未納入紀錄的原因。摘要比例條以區間全部組合的總用量為分母。
- **模型不寫死**：依使用紀錄自動納入模型與強度，包含現有、已下架及未來模型；不同版本分開計算。從未使用的模型不列入。
- **首次匯入**：背景讀取 `CODEX_HOME`（未設定則為使用者的 `.codex`）下 `sessions` 與 `archived_sessions` 的 JSONL 紀錄。新檔案優先處理，每 10 秒讀取新增部分，每 60 秒尋找新檔案。「立即更新」也會檢查新檔案。
- **關閉再開**：App 關閉期間 Codex 留下的紀錄，下次啟動會補入。重新掃描、封存及 fork 的歷史複本不重複加總；已匯入數字不因原始紀錄被清除而消失。

### 數字如何計算

只使用 `token_usage_record.usage` 的逐次回應用量，以 `response_id` 去重，再用 Codex 的回合 UUID 對應當時的 `turn_context.model` 與 `effort`。一個回合可能有多次模型回應，會全部累計。子任務／fork 可包含父任務的歷史標頭，依回合 UUID 對應，避免誤用父任務設定。

輸入已包含快取輸入，輸出已包含推理 Token；這些明細**不再次加進總數**。不把回合累計、對話累計與逐次用量相加。

### 統計範圍與不完整資料

這是「本機已記錄用量」，不是整個帳號或所有裝置的總用量，也不換算訂閱額度或費用。分類依紀錄中的回合設定，不能保證未記錄的服務端模型轉送都可辨識。

只有舊版 `token_count` 累計事件的紀錄不推算、不納入總量；在明細的涵蓋說明中標示。缺少模型／強度或可辨識但無法歸屬的轉送，列為「未知」；同一回合的設定互相衝突也列為未知。回應 ID 的用量互相衝突時排除該回應並標示。缺少必要用量、格式損壞或過大的紀錄行不當成零。

「—」代表來源沒有提供完整明細，不是零；摘要總量為「—」代表尚無任何可核對紀錄。把游標停在狀態文字或明細底部，可查看涵蓋日期及全部歷史來源的缺漏統計。含逐次回應用量的新版紀錄，可與同回合附帶的舊累計事件共存，舊事件不會再次計費。

本機紀錄格式屬於 Codex 內部格式。遇到未來不相容格式時，保留已有資料、顯示讀取或涵蓋問題，不猜測數字。檔案被暫時鎖住或正在寫入會自動重試；資料庫無法寫入時檢查資料目錄的權限及剩餘空間。

## 資料與設定

- 指令：`%LOCALAPPDATA%\CodexUsageWidget\prompts.json`；再次保存時備份前一版為 `prompts.json.bak`。
- 原專案設定繼續使用 Windows 的 Qt 設定儲存，保留既有偏好；用量快取也沿用原位置。
- Token 統計：`%LOCALAPPDATA%\CodexUsageWidget\token_usage.sqlite3`，SQLite 保存逐次數字、模型／強度及來源讀取進度；不另存提示詞、回答內容或登入憑證。沒有新增網路傳送。
- 設定 `QUOTA_PROMPTDOCK_DATA_DIR` 可改用獨立資料目錄（包含指令、快取及 Token 資料庫）。備份資料庫前先從系統匣結束程式；若同目錄仍有 `token_usage.sqlite3-wal`／`-shm`，需一併保存。
- 指令不會傳到小工具的伺服器；程式沒有自己的伺服器。點擊後文字會進入 Windows 剪貼簿及你選擇的目標程式。
- 自動更新只檢查本專案的 GitHub Release；點選安裝更新才會安裝到使用者程式目錄。一般雙擊保持免安裝。
- 如需明確安裝與桌面捷徑，可執行 `QuotaDock.exe --install`。原有開機啟動偏好會保留。

## 從原始碼執行

需要 Windows x64、Python 3.12 以上。建議在專案內建立虛擬環境：

```powershell
py -3 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-lock.txt
.\.venv\Scripts\python.exe app.py
```

打包執行 `.\build_release.ps1`，會先執行全部測試，再產生 `release/QuotaDock.exe`。測試使用隔離的資料夾與替身，不會把文字貼到使用者的其他視窗。

升級免安裝版本前，先從系統匣結束舊版，再執行新版 `QuotaDock.exe`。原有設定與指令會保留；重複啟動會喚醒已執行的版本。

紀錄與查詢邏輯在 `token_usage.py`，背景更新與 Qt 摘要／明細在 `token_panel.py`。使用 Python 內建 SQLite，無新增第三方相依套件。`--demo` 僅使用明確標示的示範數字，不讀寫 Token 資料庫。

依指定安裝設計 Skill：

```powershell
npx ui-ux-pro-max-cli init --ai codex
npx skills add aa-on-ai/agentic-design-system --agent codex --copy --yes
```

設計規範見 [DESIGN.md](DESIGN.md)，驗證狀態見 [驗證紀錄.md](驗證紀錄.md)。原始碼的測試包含 Qt 元件操作；實際跨程式貼上及實機縮放仍需在可操作的 Windows 桌面完成驗收。
